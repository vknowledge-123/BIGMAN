Selected-stock Algo · Paper / Live / Backtest

Choose a confirmed Possible Candidate or Redwala using its Start Algo button. Select which ladder starts first below. Each session keeps the settings selected at start.

Quantity = floor(capital / entry price), without leverage. Adds use the same capital at their new price. Targets and fixed stops use each ladder's original entry price. First ladder direction applies to trading and backtests. Opposite ladders start after SL/TSL only when Reverse on SL / TSL is enabled. Reversals close all shares and open the original initial quantity on the opposite side. A target ends trading in that stock for the day.

Exits run in this application. SL, TSL and target use received websocket LTP updates. Orders use cached bid/ask; REST quotes are a fallback with the shared 1.05-second throttle. Fills require broker reconciliation; execution is not instantaneous or price-guaranteed. Keep the server, feed and internet running. Use Exit & Stop and verify zero broker quantity before closing. Scanner Stop does not stop algos. Live orders require valid Dhan credentials and a whitelisted static IP.

Algo Backtest

Uses the algo controls above and saved scanner filters. Checks setup qualification before entry. The entry candle uses only its close for exit checks, trailing updates and adds; its high/low are ignored. From the next candle, OHLC checks apply. Backtests reverse ladders only when the candle closes at or beyond SL/TSL, using that close plus slippage. New-position stop checks begin next candle. Live/paper trading still reverses immediately. Historical replay never places real orders, including when LIVE mode is selected. One-minute OHLC replay cannot reproduce tick order or actual bid/ask fills.
